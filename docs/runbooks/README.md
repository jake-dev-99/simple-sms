# Runbooks

Operational procedures for `simple_sms_native`.

Release + deploy are automated via `.github/workflows/release.yml` and
`.github/workflows/deploy.yml` (`main`-only, tag-driven); version history is in
[`../../CHANGELOG.md`](../../CHANGELOG.md). Add rollback / incident
procedures here as they're needed. For day-to-day build/test/verify
commands, see [`AGENTS.md`](../../AGENTS.md).
